# ASR model-comparison inputs

These files were uploaded alongside the Colab ASR comparison notebook:

- `fleurs_fa_ir_test_metadata.csv`: 871-row FLEURS metadata table with the
  original Colab audio paths, sample rate, and duration.
- `fleurs_fa_ir_recording_manifest.csv`: 871-row recording manifest used for
  experiment preparation.

They are preserved as provenance inputs. Their `/content/drive/...` paths are
historical and are not rewritten for local execution.
